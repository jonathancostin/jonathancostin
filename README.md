# Jonathan Costin

Hands-on engineer: infrastructure, full-stack software and tools for working with AI coding agents. I started as a CNC machinist and machine builder, spent a couple of years running Microsoft 365 and identity at a managed IT provider, and now build software.

## What I'm building

- **[tuitree](https://github.com/8thlyr/tuitree)**: a terminal dashboard for git worktrees and GitHub PRs, for when you run several coding agents at once. Rust and ratatui, prebuilt releases and a Homebrew formula.
- **[Fan Curve](https://github.com/8thlyr/fan-curve)**: a macOS menu-bar app that sets fan speed from CPU temperature. Swift, with a background helper that hands control back to macOS on sleep, quit or lost contact.
- **[runtest](https://github.com/8thlyr/runtest)**: put it in front of an agent's test command and macOS runs it at background priority, so the laptop stays usable.
- **An internal operations platform for a small hospitality company**: properties, deals, documents and contacts. TypeScript, React, Express, Microsoft sign-in, Postgres. (Private client work.)

## Earlier tooling (Microsoft 365 and endpoint admin)

- **[o365Reporter](https://github.com/jonathancostin/o365Reporter)**: PowerShell, Microsoft Graph and Exchange Online. Active and inactive users, licenses, MFA method and devices to CSV.
- **[pslib](https://github.com/jonathancostin/pslib)**: a PowerShell 7 module of 35 Microsoft 365 admin functions, with a terminal UI.
- **[Intune](https://github.com/jonathancostin/Intune)**: gets domain-joined Windows devices auto-enrolled into Intune.
- **[intuneaudit](https://github.com/jonathancostin/intuneaudit)**: audits Intune device compliance against a conditional-access group and reports it to CSV.
